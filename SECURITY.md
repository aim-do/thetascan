# Security policy

## Supported versions

Security fixes are applied to the latest published ThetaScan release. The
initial supported line is `0.1.x`.

## Reporting a vulnerability

Do not open a public issue containing an exploit, credential, private model or
dataset location, or other sensitive material. Send a concise report to
[hi@aim.do](mailto:hi@aim.do), including the affected version, impact, and a
minimal reproduction where it is safe to do so.

ThetaScan is research software. Users remain responsible for sandboxing
untrusted model artifacts and configuration files and for reviewing external
dependencies before deployment.
