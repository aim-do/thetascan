# ThetaScan paper versions

The paper is maintained as a versioned technical report while the architecture
and its parameter search are still developing. Each public preview is a
citable snapshot; a later preview may add experiments, mechanisms,
collaborators, or corrected claims without silently replacing the identity of
an earlier version.

## Public Preview v0.1 - 2026-07-24

Status: **Preliminary**.

This is the first numbered public preview of *ThetaScan: Scan-Parallel
Nonlinear Memory*. It presents the slow-memory/fast-memory formulation,
the two write rules, normalized reads, random feature expansion, temporal-mode
banks, and the completed single-seed 7,500-step five-arm benchmark. It is not
an archival or final paper, and the parameter search is ongoing.

The software release and paper version are independent: this paper preview
accompanies software `0.1.0`, but future paper previews need not imply a
software API release.

Citations should include the exact repository commit, tagged release, or
archive identifier used. A publication release may add a tag without changing
the paper version.

## Update policy

- Substantive changes to data, algorithms, claims, authorship, or conclusions
  advance the paper preview version and add a dated entry here.
- Typographical or rendering-only corrections may keep the same paper version,
  but should be recorded here if they affect a published artifact.
- Released Markdown and PDF files should carry the same version and date.
- Stable public versions should remain recoverable through repository history,
  a release, or an archive rather than being represented as the original text.
- A future archival submission can receive its own venue version while citing
  the public-preview lineage.

This policy makes frequent research updates expected rather than problematic:
new evidence should produce a new, clearly dated preview instead of making the
preliminary report appear final.
