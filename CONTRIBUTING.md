# Contributing

Issue reports, reproducibility reports, documentation corrections, and focused
design discussion are welcome. The current research priorities are optimizer
and schedule design for faster convergence, fused scan/FLA performance work,
the persistent streaming-state API described in [ROADMAP.md](ROADMAP.md),
systematic parameter selection, independent replication, and long-context or
high-load evaluation.

ThetaScan is source-available, patent pending, and may also be offered under
separate commercial terms. For that reason, the project does not currently
accept unsolicited code contributions. Contact [hi@aim.do](mailto:hi@aim.do)
before opening a code pull request. A substantive code contribution can be
merged only after an appropriate written contributor agreement with
Ultimamind SRL covering copyright, patent rights, and relicensing has been put
in place.

Do not submit confidential information, unpublished third-party code, model or
dataset artifacts without redistribution rights, credentials, checkpoints, or
benchmark result archives. Opening an issue does not grant permission to use
confidential or patented material beyond the repository's existing licenses.
